# ComposeRichEditor 0.1.0-alpha01 发布草稿

[English](./0.1.0-alpha01.md)

这是 ComposeRichEditor 的第一个公开 alpha 版本。ComposeRichEditor 是一个面向 Android、iOS、Desktop 和 Web 的 Compose Multiplatform 富文本编辑器库。

## 亮点

- 提供三个可发布 artifact：`compose-richtext-core`、`compose-richtext` 和 `compose-block-richtext`。
- 提供可直接使用的普通富文本编辑器，包含格式化工具栏、emoji 面板、超链接弹窗、JSON 导出、撤销/重做和平台特定输入处理。
- 提供实验性的块级编辑器，包含文本块、表格编辑、块导航和共享浮动工具栏行为。
- 支持 Android、iOS、Desktop JVM 和实验性的 Web 目标。
- 使用 Apache-2.0 许可证，并提供 README、更新日志、贡献指南和安全策略的中英文文档。

## 安装

```kotlin
dependencies {
    implementation("io.github.taocent:compose-richtext-core:0.1.0-alpha01")
    implementation("io.github.taocent:compose-richtext:0.1.0-alpha01")
    implementation("io.github.taocent:compose-block-richtext:0.1.0-alpha01")
}
```

普通编辑器使用 `compose-richtext`。只有需要块级编辑或表格块工作流时，再额外引入 `compose-block-richtext`。

## 实验性 API 提醒

块级编辑器 API 在本 alpha 版本中是实验性的，需要显式 opt-in：

```kotlin
import com.taocent.simple.compose.component.blockrichtext.ExperimentalBlockRichTextApi

@OptIn(ExperimentalBlockRichTextApi::class)
@Composable
fun BlockEditorScreen() {
    val state = rememberBlockState()

    BlockRichTextEditor(state = state)
}
```

普通富文本编辑器 API 会比 `blockrichtext` 更稳定，但所有 API 在 `1.0.0` 前仍可能调整。

## 重要变更

- 将 Maven Group ID 统一为 `io.github.taocent`。
- 添加 Maven 发布元信息、远程仓库配置和基于环境变量的签名配置。
- 添加 GitHub Actions CI，用于 JVM 测试、common/JVM 编译、iOS 模拟器编译和 Maven Local 发布验证。
- 将 `CustomEmoji` 和 `DefaultCustomEmojis` 迁移到 `richtext-core` 的公开 API 包。
- 为块级编辑器 API 添加 `ExperimentalBlockRichTextApi` 标记。
- 更新 README 和 CHANGELOG，说明 artifact、API 状态和发布配置状态。

## 已知限制

- 这是 alpha 版本；公开 API 名称、包结构和行为在稳定版前可能变化。
- `blockrichtext` 仍为实验性模块，后续 alpha 版本可能包含破坏性调整。
- Web 支持仍为实验性，行为可能无法完全对齐 Android、iOS 和 Desktop。
- 部分包名仍使用原始项目命名空间，`1.0.0` 前可能调整。
